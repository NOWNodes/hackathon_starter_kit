# Quickstart

1. Copy `.env.example` to `.env`.
2. Set `NOWNODES_API_KEY`. The same key is used by Solana, Bitcoin, and Ethereum examples.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:3000`.

Use `npm run verify:nownodes` to prove the configured NOWNodes Solana and Bitcoin endpoints are reachable.
